  ✅ Visual Toggle Switch (OFF=Gray, ON=Purple)
  ✅ Saves to localStorage (persists across sessions)
  ✅ Animated Notifications on Switch

How It Works:
  Static Mode  = Content from HTML files (default)
  Dynamic Mode = Content from Database/API (future)

💡 FOR DEVELOPERS
═══════════════════════════════════════════════════════════════════════

To check content mode in your code:
  
  const mode = localStorage.getItem('vvel_content_mode');
  
  if (mode === 'dynamic') {
    // Load from API
  } else {
    // Use static content
  }

All page IDs follow pattern: {pageName}Page
Example: 'dashboard' → 'dashboardPage'
